# 말씀 콘텐츠 검수표

앱에 들어 있는 초기 말씀 목록입니다. 모든 항목은 편집자(Claude)가 퍼블릭 도메인 원전(팔리어 경전, 한문 경전·어록)을 바탕으로 **새로 옮긴 번역**이며, 특정 출판사의 번역문은 사용하지 않았습니다.

현재 모든 항목은 `verified: false`이므로 앱에서 **"출처 확인 중"** 배지가 함께 표시됩니다. 검수 절차는 다음과 같습니다.

1. 아래 표의 출처(경전·게송 번호)를 원전 또는 신뢰할 수 있는 대조본(예: SuttaCentral의 팔리어 원문, CBETA의 한문 대장경)과 대조합니다.
2. 번역이 원문의 뜻과 맞는지 확인하고, 필요하면 `app/src/main/assets/data/quotes_ko.json`의 `text`를 고칩니다.
3. 확인을 마친 항목은 `"verified": true`로 바꿉니다.
4. 내용을 바꿨다면 `manifest.json`의 `contentVersion`을 1 올립니다. 그래야 이미 설치된 앱에도 반영됩니다.
5. `python3 tools/validate_content.py`로 형식을 검사합니다.

`요약` 표시는 원문을 줄이거나 풀어 쓴 항목이라 원문 대조가 특히 필요합니다.
